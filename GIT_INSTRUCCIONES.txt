Opción 1: Si es un repositorio NUEVO
=====================================

1. Crear repositorio en GitHub/GitLab/etc.

2. Agregar remote:
   git remote add origin <URL-del-repositorio>

3. Push inicial:
   git push -u origin main

Opción 2: Si es un repositorio EXISTENTE
========================================

1. Verificar remote:
   git remote -v

2. Push de cambios:
   git push origin main
